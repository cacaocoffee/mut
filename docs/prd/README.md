## 부록 A는 폐기됐다

부록 A는 `시안 미확인` 상태에서 쓴 **제안안**이었고, 문서 스스로
"시안 파일을 받으면 팔레트와 타이포를 그쪽 기준으로 교체한다"고 못박아 뒀다.

시안이 확보된 뒤 대조해보니 색 · 서체 · 라운드 · elevation · 스페이싱이 전부 달랐고,
당도 스케일도 3단으로 적혀 있어 [ADR-0002](../decisions/ADR-0002-taxonomy.md)와 어긋났다.
**청자·주칠 팔레트가 남아 있으면 언젠가 복붙되므로 본문을 삭제했다.**

디자인 관련은 전부 [`docs/design/`](../design/)를 본다.
폐기 경위와 대조표는 [ADR-0001](../decisions/ADR-0001-design-system.md)에 있다.
