# 릴리즈 체크리스트

> **사람이 확인하는 것만 담는다.** 자동으로 막을 수 있는 것은 CI 에 있다 (SPEC-04 §9.1) —
> 여기에 옮겨 적으면 두 벌이 되고, 사람 쪽은 곧 형식이 된다.
>
> 근거는 [SPEC-04 §9.2·§9.3](spec/SPEC-04_비기능요구사항.md) 이다.

## 이 문서를 쓰는 법

배포 전에 **매 릴리즈** 절을 위에서 아래로 실행한다. 항목마다 무엇을 하는지가 적혀 있다 —
"확인한다" 로 끝나는 줄은 두지 않는다. 어디서 확인하는지 모르면 아무도 확인하지 않는다.

**차단**이라고 적힌 항목이 하나라도 실패하면 **나가지 않는다.** 경고는 기록하고 나간다 —
무엇을 안고 나갔는지가 남아야 다음 릴리즈에서 갚을 수 있다.

CI 가 이미 막는 것은 여기 없다: axe 위반(`NFR-A-01~03`·`A-05`), Lighthouse 예산
(`NFR-P-01~03`), 사이트맵 규칙(`NFR-S-02~03`), 코퍼스 불변식(`NFR-D-01`), 번들 크기
(`NFR-P-04`, 경고), 계약 재생성 일치.

## 매 릴리즈

### 키보드와 보조기기

- [ ] **키보드만으로 전 흐름을 돈다** — 탐색 → 필터 적용 → 상세 → 레시피 담기 → 파인더 4문항.
      마우스를 쓰지 않는다. 포커스가 사라지거나 순서가 튀는 곳이 없어야 한다 (`NFR-A-04` · **차단**)
- [ ] **결과가 0인 필터 칩**을 스크린리더로 듣는다 — `disabled` 와 개수 `0` 이 함께 읽힌다.
      흐린 색만으로 비활성을 알리면 안 된다 (`NFR-A-06` · 경고)
- [ ] **색을 빼고 본다** — macOS 그레이스케일 필터를 켜고 탐색·상세를 훑는다. 당도 태그·
      선택된 칩·제휴 라벨이 색 없이도 구분되는지 본다 (`NFR-A-08` · **차단**)
- [ ] **동작 줄이기를 켜고 본다** — 시스템 설정에서 켠 뒤 페이지 전환과 칩 반응을 본다.
      전환이 즉시 끝나야 한다 (`NFR-A-09` · 경고)
- [ ] 차트 — **해당 없음.** 맛 프로필 레이더(`FR-COCKTAIL-023`)는 P1 이라 1a 에 없다.
      들어오는 릴리즈에서 `role="img"`·`aria-label`·수치 표 병기를 본다 (`NFR-A-07` · **차단**)

### API 가 죽었을 때

- [ ] **API 를 끄고 정적 페이지를 연다** — 칵테일 상세·카테고리·법적 페이지가 그대로 뜬다.
      `NFR-R-01` 은 SSG 를 고른 이유의 절반이라, 여기서 실패하면 설계 결함으로 **즉시 조사**한다
- [ ] **API 를 끈 채로 검색·필터를 쓴다** — 실패하는 것은 검색·필터뿐이고, 화면에 무엇이
      안 되는지 안내가 뜬다. 빈 결과처럼 보이면 안 된다 (`NFR-R-02` · **차단**)

### 공유 카드

- [ ] **카카오톡에 링크를 보내 카드가 뜨는지 본다** — 칵테일 상세·카테고리·홈 각 1건.
      카카오는 카드를 캐시하므로 [카카오 디버거](https://developers.kakao.com/tool/debugger/sharing)
      로 캐시를 갱신한 뒤 다시 본다 (`NFR-S-06`)
- [ ] 한글이 깨지지 않는지 본다 — OG 이미지는 폰트를 따로 실어 그린다

### 법적 표기

- [ ] **과음 경고와 미성년자 문구**가 모든 공개 페이지 하단에 있다 (`NFR-L-01` · **차단**).
      e2e 가 매 화면을 검사하지만, 새 화면이 늘었는데 검사에 안 들어간 경우를 사람이 본다
- [ ] **제휴 라벨을 끌 수 없다** — 1a 에서 적용점은 재료 브랜드 하나다. 라벨이 설정으로
      꺼지거나 작아지거나 흐려지지 않는다 (`NFR-L-02` · **차단** · 공정위)
- [ ] **파트너 배지와 제휴 라벨이 다른 색**이다 — 1b 대비다. 지금은 색 상수가 분리돼
      있는지만 본다 (`NFR-L-03` · **차단**)
- [ ] 개인정보 처리방침·이용약관 페이지가 열리고 **문안이 플레이스홀더가 아니다**
      (`NFR-L-04` · 실사용자 수집 차단 · [DECISIONS D-7](issues/DECISIONS.md))

### 인수

- [ ] **에디터가 개발자 없이 1건을 발행한다** — 어드민만으로 새 칵테일을 만들고 발행까지
      간다. 발행 조건 패널이 무엇이 모자란지 한 화면에 보여 줘야 하고, 개발자에게 묻는
      순간이 있으면 실패다 (`NFR-O-01`)

## 정식 오픈 전 1회

트리거 기반이다 (SPEC-04 §8.1) — **정식 오픈이 곧 변호사 자문 시점은 아니다.**

### 실사용자를 받기 전

- [ ] **호스팅 확정** ([G-07](prd/GAPS.md#g-07))
- [ ] **이미지 저장소 확정** ([G-07](prd/GAPS.md#g-07)) — 지금 사진은 전부 자리표시자다
- [ ] 개인정보 처리방침·이용약관 **문안** — `audit_log` 가 탈퇴 후에도 남는다는 예외를
      명시한다 (SPEC-08 §5.3 · `NFR-L-04`)

### 유료 브랜드 노출을 시작하기 전

- [ ] **주류 광고 규제 자문** (`NFR-L-05`) — 광고를 시작할 때고, 그때는 계약서도 필요하다.
      개발이나 오픈을 막는 항목이 아니다 (SPEC-04 §8.1 개정)
