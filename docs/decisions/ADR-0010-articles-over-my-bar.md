# ADR-0010 — 내 술장을 로드맵에서 빼고, 아티클을 앞당긴다

- 상태: 채택 (2026-08-20)
- 관련: [ADR-0009 매거진판](./ADR-0009-design-magazine.md) · SPEC-01 §4.4·§5 · SPEC-05 §렌더 표 · `FR-CONTENT-001` · `R-F2.2-*`

## 배경

내 술장(`/my-bar`)은 Phase 2 `STOCK` 도메인을 2026-08-20 에 앞당긴 것이었다
(SPEC-01 §4.4 노트). 화면은 돌지만, 지금 단계의 제품이 먼저 증명해야 하는 것은
SPEC-01 §4.3 이 말하는 **콘텐츠 품질과 SEO 가설**이다 — 담아 둘 유저보다
읽으러 올 유저가 먼저다. 운영자의 판단으로 내 술장은 앞당김 취소를 넘어
**로드맵 자체에서 뺀다.**

운영자는 칵테일·바·위스키 글을 쌓아 온 블로그(Shaking Like Bartender)를 갖고 있고,
그 글이 곧 콘텐츠 품질 가설의 재료다. PUNCH(punchdrink.com)처럼 사진 카드와
긴 본문으로 읽히는 아티클 섹션이 그 그릇이다.

## 결정

1. **내 술장을 로드맵에서 뺀다.** `/my-bar` 화면·네비 탭·로컬 저장 훅·`stock.ts` 를
   걷어내고, `R-F2.2-*`(PRD §7.2) · `FR-STOCK-001~005` · `/me/stock` · `user_stock` 을
   **폐기**한다. Phase 2 복귀가 아니다 — SPEC-01 §5 명시적 비범위로 옮긴다.
   요구사항 본문은 기록으로 남기고 폐기 표시만 단다 (부록 A 폐기와 같은 방식 · ADR-0001).
2. **`CONTENT` 의 아티클을 앞당긴다.** 서버 없이 화면만이다 — 본문은
   `packages/domain/src/articles/` 의 정적 데이터로 두고, `GET /articles` 와
   `article` 테이블(SPEC-06 §3.6)·어드민 발행은 그대로 Phase 2 다.
3. **경로는 `/articles` 다.** SPEC-05 렌더 표는 `/stories/[slug]` 라 적었지만
   SPEC-07 은 `GET /articles` 로, SPEC-06 은 `article` 테이블로 부른다 — 문서끼리
   이미 어긋나 있었다. 테이블·API 와 같은 이름으로 통일하고 SPEC-05 를 고친다.
4. **주제 축은 화면 전용으로 시작한다.** 카테고리 `cocktail`(칵테일) ·
   `bar`(바) · `whisky`(위스키)는 지금 있는 글의 묶음이다. SPEC-02 §6 의 발행 형식 축
   (`interview`·`guide`·`trend`·`photo_essay`)과는 다른 축이고, 두 축의 관계는
   API 계약을 만들 때 정한다 — [GAPS G-49](../prd/GAPS.md).

## 이관 규칙

- 첫 콘텐츠는 운영자 본인 블로그 글 9편이다 (카테고리별 3편). 저작권자가 본인이며,
  각 아티클 하단에 원문 링크를 남긴다.
- 협찬 글은 이번에 가져오지 않았다. 가져오게 되면 `제휴 콘텐츠` 라벨이 의무다
  (`NFR-L-02` · 배포 차단).

## 결과

- 되는 것: `/articles` 목록 · `/articles/[slug]` 상세 9편 · 사이트맵 색인 ·
  아티클→칵테일 상세 연결.
- 폐기되는 것: 내 술장 화면 · `/me/stock` API · `user_stock` 테이블 ·
  보유 재료 필터(PRD §7.1) · KPI 「내 술장 3개+ 등록 유저」(대체 지표는
  [GAPS G-50](../prd/GAPS.md)).
- 그대로 Phase 2 인 것: 통합 검색의 아티클 그룹(`FR-SEARCH-008`) · 어드민 발행 ·
  큐레이션 리스트.

## 손익

얻는 것 — 블로그에 쌓인 글이 제품 안으로 들어오고, 색인할 콘텐츠 면이 넓어진다.
잃는 것 — 「재료 1개만 더」(`R-F2.2-2`, PRD 가 "체류와 재방문의 핵심 동인"이라 부른 것)와
Difford's 가 유료로 파는 역검색을 버린다. 코드는 git 이력에 남아 있으니, 다시 원하게 되면
이 ADR 을 뒤집는 새 ADR 로 살린다.
