# ADR-0009 · 디자인 시스템을 매거진판으로 교체한다

| | |
|---|---|
| 상태 | 확정 |
| 일자 | 2026-08-20 |
| 대체 | [ADR-0001](./ADR-0001-design-system.md)의 "Modernist 채택" 결정 (라이트 단일 테마 결정은 유지) |
| 관련 갭 | [G-45](../prd/GAPS.md#g-45) |

## 맥락

Modernist(흰 바탕 + 단색 빨강 + Archivo 800)는 ADR-0001로 채택돼 전 화면에 구현됐다.
운영자가 실물을 쓰면서 "AI가 만든 것 같은 전형적인 인상"이라는 판단을 내렸고, 색·서체·
레이아웃 전반의 교체를 결정했다. 서로 다른 방향의 시안 3벌(매거진 · 바 무드 · 도감)을
실데이터로 만들어 비교한 뒤 **매거진판**을 골랐다.

교체는 ADR-0005가 정한 절차를 따른다 — GAPS 등재([G-45](../prd/GAPS.md#g-45)) →
이 ADR → 아래 되돌리는 조건.

## 결정

**1. 토큰 정본(`packages/ui/styles.css`)의 값을 매거진판으로 교체한다.**

| | Modernist (이전) | 매거진판 (이후) |
|---|---|---|
| 그라운드 | `#f3f2f2` (무채 흰색) | `#f6f3eb` (아이보리) |
| 텍스트 | `#201e1d` | `#241e18` (웜 블랙) |
| accent | `#ec3013` (빨강) | `#93293b` (와인) |
| accent-2 | `#e15b47` | `#9f5c54` (로즈 브라운) |
| 제목 서체 | Archivo 800 | **Fraunces 600 + Noto Serif KR** (세리프) |
| 본문 서체 | Archivo + Noto Sans KR | **IBM Plex Sans KR** |
| 램프 | OKLCH 공통 명도 스케일 | **같은 스케일 유지** — 단(step)의 의미가 안 바뀐다 |

램프의 명도 스케일을 그대로 쓰므로 `contrast-check.mjs`의 토큰 쌍 등록과
`accent-700 = 글자용` 규칙(ADR-0006)이 그대로 성립한다. 실측:

- 본문 `text on bg` 14.87:1 · 탭 비선택 5.85:1 · 탭 선택(accent-700) 6.29:1
- `.btn-primary`(bg on accent-700) 6.29:1 — ADR-0006의 accent-700 결정 유지
- **accent 원색이 7.23:1** — Modernist의 "accent는 본문에 못 쓴다(3.76:1)" 제약이
  값으로는 해소됐다. 다만 가드(`css-guard` 게이트 14)와 SPEC-04 §2.1 실측표는
  당장 갱신하지 않고 accent-700 규칙을 유지한다 — 완화는 실측표 갱신과 함께 별도로.

**2. 화면 층(`packages/ui/app.css`)을 매거진 문법으로 고친다. 클래스명과 DOM은 유지한다.**

- 마스트헤드: 워드마크 중앙 정렬, 탭은 세리프로 그 아래 —
  선택 표시는 밑줄 인디케이터 유지 (ISSUE-055의 결정은 그대로).
- 탐색 필터: 좌측 사이드바 → **가로 색인 띠** (축 이름 왼쪽, 값은 옆으로 흐른다).
  칩은 **뱃지**다 — 기본은 테두리 상자, 호버는 테두리 진해지고 옅게 채워지고,
  선택은 accent-700 채움 + 밝은 글자. 밑줄 문법은 내비 탭·쪽 넘김에만 남는다.
  *(처음엔 칩도 밑줄로 갔으나 실사용에서 호버·선택이 티가 안 나 뱃지로 되돌렸다.)*
- 칵테일 카드: 상자(surface 배경 + 테두리) → **헤어라인 위 목록 항목**.
- 강한 규칙선은 `--color-text`(3px), 조직 구분은 기존 `--color-divider` 유지.
- 클래스명을 유지하므로 e2e 셀렉터 68곳과 `css-guard`의 클래스 지목 검사가 깨지지 않는다.

**3. Modernist에서 계승하는 것** — 이번 교체의 대상이 아니다.

- **라운드 0** · **전부 왼쪽 정렬** · **구분선이 조직화를 전담** · **사진은 `.grayscale`**
- **라이트 단일 테마** (ADR-0001 결정 3— 유지)
- 밑줄 인디케이터(ISSUE-055) · accent-700 글자 규칙(ADR-0006) · 탭 44px(WCAG 2.5.8)

**4. 시안 원본의 지위.** `docs/design/source/MUT.dc.html`(Modernist 원본)은 역사 기록으로
남긴다. 매거진판의 시안은 세션 산출물(Artifact 3벌 중 A안)이고 저장소 밖에 있으므로,
**이제 정본은 `styles.css` 하나다** — "시안 원본과 함께 고친다"(ADR-0001 결과 항목)는
이 ADR로 소멸한다. `color-parity.mjs`의 BASELINE이 그 자리를 맡는다 — hex 정본을
스크립트가 들고, styles.css의 oklch 표기가 왕복으로 일치해야 한다.

## 결과

- `color-parity.mjs` BASELINE을 매거진판 hex 32색으로 교체했다.
- 폰트 주입(`app/layout.tsx`)이 Archivo·Noto Sans KR → Fraunces·IBM Plex Sans KR로
  바뀌고, `css-guard.mjs`의 APP_PROVIDED 목록이 따라간다.
- `lib/og-card.tsx`의 hex 4개(OG 이미지는 CSS 변수를 못 쓴다)를 같은 값으로 맞췄다.
- 어드민 화면은 레이아웃을 안 바꾸고 새 토큰만 물려받는다 — 후속에서 다듬는다.
- SPEC-04 §2.1 실측표 갱신, 카드 마크업 단일화(`category-page`의 인라인 `.card`),
  내 술장·재료 사전 화면의 매거진 심화는 후속 이슈로 남긴다.

## 되돌리는 조건

교체 후 핵심 지표(탐색 진입→상세 전환, 파인더 완주율 — SPEC-10)가 유의미하게
떨어지면 이 커밋 한 벌을 되돌린다. 토큰·CSS·가드 표가 한 PR에 있으므로 revert 로
Modernist가 그대로 돌아온다. 시안 원본(`docs/design/source/`)은 그때를 위해 남겨 둔다.
