# ADR-0007 · 호스팅은 Vercel · Neon · R2 로 하고, 웹부터 혼자 올린다

| | |
|---|---|
| 상태 | 확정 |
| 일자 | 2026-08-20 |
| 결정자 | 제품 |
| 관련 갭 | [G-07](../prd/GAPS.md#g-07) 하단 — 호스팅 · 이미지 저장소 |
| 관련 스펙 | [SPEC-05](../spec/SPEC-05_아키텍처.md) · [SPEC-07 §1.2](../spec/SPEC-07_API명세.md) · [SPEC-00 `PRIN-T02`](../spec/SPEC-00_개발원칙.md) |

## 맥락

[G-07](../prd/GAPS.md#g-07)이 2026-08-06에 DB(PostgreSQL 16) · CMS(자체 어드민) ·
백엔드(Kotlin + Spring)를 확정하면서 **호스팅과 이미지 저장소 두 건을 남겼다.**
그때 적힌 대로 이건 스펙을 더 써서 풀리는 문제가 아니라 값과 제약을 견주는 문제다.

제약이 셋이다.

**하나 — 값이 기준이다.** 제품이 "최대한 저렴하게" 로 정했다. 트래픽이 아직 0인 단계라
**안 써도 나가는 고정비**가 가장 나쁜 형태다.

**둘 — 정본은 프론트와 API가 같은 상위 도메인이어야 한다고 적었다.**
[SPEC-07 §1.2](../spec/SPEC-07_API명세.md)가 세션을 `httpOnly` · `Secure` · `SameSite=Lax`
쿠키에 담기로 했고, 거기 경고가 붙어 있다. 그대로 읽으면 `*.vercel.app` 과 `*.fly.dev` 는
상위 도메인이 달라 쿠키가 넘어가지 않으므로 **로그인을 붙이려면 도메인을 사야 한다.**

다만 이 제약이 필요한 것보다 좁을 수 있다. 브라우저는 이미 API를 직접 부르지 않고
Next 프록시만 부른다 — 자세한 것은 [G-45](../prd/GAPS.md#g-45)에 올렸고 아래
「$0 으로 끝낼 수 있는가」에서 값에 어떻게 걸리는지 다룬다. **판정 전이므로 이 ADR은
도메인이 필요한 경우와 아닌 경우를 모두 열어 둔다.**

**셋 — 웹이 API 없이도 빌드된다.** [`apps/web/lib/api.ts`](../../apps/web/lib/api.ts)가
`MUT_API_URL` 이 비면 API를 부르지 않고 `packages/domain` 의 배열로 빌드한다.
CI가 지금 그렇게 돌고 있다. 이건 원래 화면 작업과 서버 작업이 서로를 막지 않게 하려고
둔 것인데, **배포를 나눌 수 있게도 해 준다.**

## 비교한 안

| 안 | 월 비용 | 대가 |
|---|---|---|
| AWS 한 벌 (ECS + ALB + RDS) | **$60~90** | 트래픽이 0이어도 그대로 나간다. ALB 만 월 $16, RDS 최소 $15 |
| Railway 한 벌 | **$5~7** | 한 군데로 끝나고 Postgres가 클릭 한 번. 다만 RAM이 $10/GB·월이라 JVM + Postgres가 크레딧 $5를 넘긴다 |
| **Vercel + Neon + R2** (+ Fly 또는 Cloud Run) ← 택함 | **$0 → ~$3** | 네 군데를 본다. 대신 1단계가 $0이고 쓰는 만큼만 는다 |

Railway의 `Free` 플랜(월 $1)은 **RAM 0.5GB** 라 이 API가 들어가지 않는다 —
`data-jpa` 와 `batch` 를 포함한 지금 의존성이면 실측 400~600MB다.

## 결정

### 층별로 어디에 두나

| 층 | 어디 | 왜 | 값 |
|---|---|---|---|
| 웹 | **Vercel** | Next.js를 만든 곳이라 ISR과 `ImageResponse` 가 손대지 않고 돈다 | Hobby $0 |
| API | **Fly.io** 또는 **Cloud Run** | 둘 다 컨테이너 하나면 된다. 아래 「$0 으로 끝낼 수 있는가」에서 고른다 | $0 ~ $3.19 |
| DB | **Neon** | PostgreSQL 16 · 안 쓰면 자동으로 멈춘다 | 무료 0.5GB |
| 이미지 | **Cloudflare R2** | **S3 호환**이라 `media_asset.storage_key` 가 그대로 맞는다 | 10GB 무료 |

R2를 고른 이유는 값이 아니라 **나가는 트래픽이 무료**라는 점이다. 이미지는 트래픽이
곧 비용인데, S3였다면 그게 청구서에서 가장 큰 항목이 된다.

### 세 단계로 나눠 올린다

| 단계 | 무엇 | 값 | 막는 것 |
|---|---|---|---|
| **1** | 웹만 Vercel. `MUT_API_URL` 을 비운 채로 | **$0** | 없음 |
| **2** | API + DB | **$0~3** | 없음 — [G-45](../prd/GAPS.md#g-45) 판정 완료(2026-08-21): 도메인 없이 된다 |
| **3** | 이미지 R2 | ~$0 | 없음 — 아티클 사진 73MB 가 생겨 옮길 것이 생겼다 (ADR-0010 이후) |

> **G-45 판정(2026-08-21)** — 브라우저는 웹 오리진의 프록시만 부르므로 세션 쿠키도
> 웹 오리진에만 있으면 된다. 도메인 구매는 2단계의 선행 조건이 아니다.
> 배포 조건 세 가지(빈 `cookie-domain` · `redirect-base` = 웹 오리진 · 인가 진입을
> 웹 오리진 경로로)는 G-45 판정문에 있다.

1단계가 성립하는 근거는 위의 제약 셋 중 마지막이다. 다만 정직하게 적어 둔다 —
`api.ts` 는 그 폴백을 **"빌드 부트스트랩이지 런타임 경로가 아니다"** 라고 못박았다.
1단계는 그 폴백을 한 번 더 의도적으로 쓰는 것이고, `MUT_API_URL` 을 넣는 순간 끝난다.
**1단계에서 안 도는 것**은 로그인 · 어드민 · `/search` 셋이다. 서버를 부르기 때문이다.
탐색 · 파인더 · 내 술장 · 재료 사전 · 상세는 전부 돈다.

`/search`(통합 검색)만 **눈에 보이게 빈다** — 셸만 미리 그리고 질의를 전부 API에 맡기는
화면이라 받을 곳이 없다. 내비에서 뺐고 `noindex`라 주소를 직접 쳐야 닿지만, 1단계에서
유일하게 비는 화면이라 적어 둔다. 탐색 화면의 검색창은 색인이 503을 주면 이름
부분일치로 물러나므로(초성과 별칭만 빠진다) 그쪽은 쓸 수 있다.

### 2단계를 $0 으로 끝낼 수 있는가

제품이 "처음엔 안 내고, 내더라도 적게" 로 정했다. 2단계까지 $0 이 되려면 둘이 필요하다.

**하나 — 도메인을 안 사도 되는가.** [G-45](../prd/GAPS.md#g-45)에 올렸다. 브라우저가 이미
API를 직접 부르지 않고 Next 프록시만 부르므로, 프록시가 `Set-Cookie` 를 그대로 전달하면
상위 도메인이 같을 필요가 없어 보인다. **판정 전이다.** 성립하면 도메인 값이 0이 되고,
성립하지 않으면 [Cloudflare Registrar](https://www.cloudflare.com/products/registrar/)가
원가로 판다 (`.com` 연 $10 안팎, 웃돈 없음).

**둘 — API를 무료 한도 안에 넣을 수 있는가.**

| | 무료 한도 (월) | 우리 경우 |
|---|---|---|
| **Google Cloud Run** | vCPU 180,000초 · 메모리 360,000 GiB·초 · 요청 200만 | 512MiB면 컨테이너 가동 **200시간**. `*.run.app` HTTPS 주소가 딸려 온다 |
| **Oracle Always Free** | 2 OCPU · 12GB | 상시 가동이 되지만 VM을 직접 관리하고, 용량이 없다는 응답이 잦다 |
| Fly.io | 없음 | 512MB 상시 ≈ $3.19 |

Cloud Run은 **상시 가동으로는 안 맞는다.** 1 vCPU를 한 달 켜 두면 259만 초라 18만 초를
훌쩍 넘는다. 요청이 없을 때 0으로 줄어야 하고, 그러면 **JVM 냉시동 10~25초가 첫 요청에
그대로 얹힌다.**

**그래서 GraalVM 네이티브가 「나중에 볼 것」이 아니라 무료의 전제가 된다.** 냉시동이
50ms 안팎으로 내려가야 0으로 줄이는 방식이 쓸 만해지고, 메모리도 줄어 GiB·초 한도가
오래 간다. 아래 「함께 적어 두는 것」에서 다시 다룬다.

Oracle은 2026-06-15에 4 OCPU/24GB에서 **2 OCPU/12GB로 줄었고 공지가 없었다.** 값이 0이어도
조건이 말없이 바뀌는 곳이라 주된 안으로 두지 않는다.

**정리** — 2단계는 `$0`(Cloud Run + Neon, 네이티브 이미지 필요)과 `~$3`(Fly + Neon, 지금
코드 그대로) 사이에서 고른다. 어느 쪽이든 **1단계를 막지 않으므로 지금 정하지 않는다.**

### 1단계에 반드시 넣어야 하는 환경변수

`MUT_SITE_URL` 하나다. [`apps/web/lib/site.ts`](../../apps/web/lib/site.ts)가 이게 없으면
`http://localhost:3000` 을 쓴다. 안 넣으면 OG · 사이트맵 · 구조화 데이터가 전부 로컬을
가리켜서 **카카오톡 카드가 뜨지 않는다** (`NFR-S-06`). 화면은 멀쩡해 보이므로 눈에 안 띈다.

## 안 고른 이유

**AWS** — 고정비다. 아직 아무도 안 오는 사이트에 월 $60~90을 태우는 것이 이 단계에서
할 일이 아니다. 트래픽이 붙어 고정비가 의미를 갖게 되면 그때 다시 본다.

**Railway** — 값 때문에 뺐지, 나쁜 선택이라서가 아니다. **한 군데로 끝난다**는 것이
Fly + Neon 두 군데를 보는 것보다 낫고, 그 차이가 월 $2~4다. 2단계에서 Fly 설정이
번거로우면 다시 꺼낼 만하다.

## 함께 적어 두는 것

**Vercel Hobby는 비상업 · 개인 용도로 제한된다**
([공정 사용 지침](https://vercel.com/docs/limits/fair-use-guidelines#commercial-usage)).
MUT가 상업 서비스가 되는 시점에 Pro(월 $20)로 올려야 한다. 1단계에는 걸리지 않지만
**미리 알고 있어야 하는 값**이라 여기 남긴다.

**API 메모리는 언어를 바꾸지 말고 GraalVM 네이티브로 본다.** 값의 원인이 JVM 메모리인 건
맞지만, 언어를 바꾸는 것은 본문 13,329줄과 `PRIN-T02`의 분류 축 정본을 다시 세우는
일이라 연 $50~70을 아끼자고 할 일이 아니다. Spring Boot 3+의 네이티브 이미지는 **같은
코드로** RSS를 60~100MB, 시동을 50ms 안팎으로 줄인다. 시동이 짧아지면 Fly의 "놀면 멈춤"을
쓸 수 있어 안 쓰는 동안 $0이 된다.

**2단계를 $0으로 가려면 이것이 선행 조건이다** — 위에서 본 대로 Cloud Run 무료 한도는
상시 가동을 못 받치고, 0으로 줄이면 JVM 냉시동이 첫 요청에 얹힌다. 다만 손이 많이 간다 —
JPA와 Batch의 리플렉션 메타데이터를 챙겨야 한다. **$3을 내고 Fly에 상시로 띄우는
쪽이 더 싸게 먹힐 수도 있다** — 그 판단은 2단계에서 실제로 재 보고 한다.

## 아직 안 정한 것

| | 왜 |
|---|---|
| 도메인을 사야 하는지 | [G-45](../prd/GAPS.md#g-45) 판정 전이다. 안 사도 되면 2단계가 $0이 된다 |
| API를 Fly에 둘지 Cloud Run에 둘지 | 네이티브 이미지를 실제로 구워 보고 정한다. 1단계를 막지 않는다 |
| 이미지 저장소 실제 연결 | 사진 데이터가 없다. `media_asset` 은 스키마만 있고 지금 화면 이미지는 전부 자리표시자다 |
| CDN 세부 · 캐시 정책 | 트래픽이 붙은 뒤에 본다 |
