# ADR-0001 · 디자인 시스템은 Modernist 시안을 따른다

| | |
|---|---|
| 상태 | 확정 |
| 일자 | 2026-08-06 |
| 대체 | PRD 부록 A **전체**, NFR 12장 "다크 모드가 기본 테마" |
| 관련 갭 | [G-05](../prd/GAPS.md#g-05) · [G-06](../prd/GAPS.md#g-06) |

## 맥락

PRD v1.0 부록 A는 첫 줄에 스스로 임시임을 밝혔다.

> 시안 미확인 — 기존 Claude Design 시안을 열람하지 못해 아래는 제안안이다.
> **시안 파일을 받으면 팔레트와 타이포를 그쪽 기준으로 교체한다.**
> 구조(토큰 체계, 컴포넌트 목록)는 시안과 무관하게 유효하다.

시안은 확보됐다. Claude Design 프로젝트 `27a7afff`의 Modernist 디자인 시스템이며,
원본은 `docs/design/source/`에, 실행 가능한 형태는 `packages/ui/styles.css`에 있다.

실제 값은 부록 A의 제안과 거의 정반대였다.

| | 부록 A 제안 | Modernist 시안 |
|---|---|---|
| 그라운드 | 다크 `#121715` | 라이트 `#f3f2f2` |
| 강조색 | 청자 `#4F8975` + 주칠 `#B03A2E` (2색) | 단색 `#ec3013` |
| 제목 | Gowun Batang (명조) | Archivo 800 (산세리프) |
| 본문 | Pretendard | Archivo + Noto Sans KR |
| 숫자 | JetBrains Mono | `font-variant-numeric: tabular-nums` |
| radius | 2px | **0px** — "어디에도 라운드를 주지 말 것" |
| Elevation | 그림자 없음 | `--shadow-sm/md/lg` |

## 결정

**1. 부록 A.1(컬러) · A.2(타이포) · A.6(구현 토큰)을 폐기하고 Modernist로 교체한다.**
부록 A가 지시한 대로다. 정본은 `packages/ui/styles.css`의 `:root` 블록이며,
문서가 아니라 그 파일이 단일 진실 공급원이다.

**2. 부록 A.3~A.5도 폐기한다.** *(2026-08-06 정정 — 처음에는 "구조는 유효하다"고 판단해 살렸으나,
실물을 대조해보니 남길 것이 거의 없었다.)*

부록 머리말은 "구조는 시안과 무관하게 유효하다"고 했지만 실제 내용은 그렇지 않았다.

| A.3~A.5 항목 | 실제 |
|---|---|
| radius `2px` · 필터 칩 `999px` | Modernist는 **0** |
| "그림자를 쓰지 않는다" | Modernist엔 `--shadow-sm/md/lg`가 **있다** |
| 스페이싱 `…48 / 64 / 96` | Modernist는 `4~32`만 |
| **당도 3단 스케일** | [ADR-0002](./ADR-0002-taxonomy.md)는 **4단계** |
| 컴포넌트 목록 · 계량 표기 규칙 | [`docs/design/`](../design/) · [SCREENS-01](../screens/SCREENS-01_칵테일.md)과 중복 |

살릴 것은 **모션 값 한 줄**뿐이었고, `packages/ui/app.css`로 옮겼다 —
`--dur: 160ms` · `--ease: cubic-bezier(.2,0,0,1)`.

`styles.css`가 아니라 `app.css`에 둔 이유는 **시안 정본을 원본과 어긋나게 두지 않기 위해서**다.

**3. 테마는 라이트 단일로 간다. NFR의 "다크 모드가 기본 테마"를 삭제한다.**

이게 남은 진짜 결정이었다. G-05를 "시안 우선"으로 정리해도 NFR은 별도로 다크를 요구했고,
Modernist에는 다크 테마가 **정의돼 있지 않다** — 램프가 라이트 그라운드 한 벌뿐이고
시안 readme는 "a near-mono red on white"를 시스템의 정체성으로 규정한다.

"바는 어두운 공간이니 다크"는 부록 A의 논리였고, 그 부록은 시안 없이 쓰였다.
시안이 라이트를 골랐고 이미 구현·검증됐다. 근거 없이 되돌릴 이유가 없다.

## 결과

- 다크 테마 관련 코드를 쓰지 않는다. `prefers-color-scheme` 분기도 넣지 않는다.
- `packages/ui/styles.css`의 토큰을 고칠 때는 시안 원본과 함께 고친다. 한쪽만 바뀌면 드리프트다.
  시안에 없는 토큰이 필요하면 `app.css`에 둔다.
- **PRD 부록 A 본문은 삭제했다.** 폐기 안내와 경로 안내만 남겼다 —
  청자·주칠 팔레트가 남아 있으면 언젠가 복붙된다.
- **접근성 전제 하나가 따라온다** — 시안 readme가 명시하듯 accent↔ground 대비는 **3:1**이라
  아이콘·큰 글자·인터페이스 크롬에만 쓸 수 있다. 본문 크기 텍스트에 accent를 쓸 때는
  `--color-accent-700`을 써야 WCAG AA를 넘는다. 이건 [G-16](../prd/GAPS.md#g-16)에서 명문화한다.

## 되돌리는 조건

야간 사용 비중이나 사용자 조사로 다크가 필요하다는 근거가 나오면 [G-06](../prd/GAPS.md#g-06)의
**나안**(Modernist 규칙으로 다크 램프 파생)으로 간다. 그때 비용은 램프 재생성 + 전 컴포넌트 대비 재검증이다.
