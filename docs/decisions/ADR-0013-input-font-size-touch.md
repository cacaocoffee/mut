# ADR-0013 · 터치 기기에서 입력창은 16px 이다 (`.input` iOS 확대)

| | |
|---|---|
| 상태 | 확정 |
| 일자 | 2026-09-22 |
| 결정자 | 제품 (이슈 [082](https://github.com/cacaocoffee/mut/issues/219)) |
| 관련 갭 | [G-51](../prd/GAPS.md#g-51) |
| 관련 ADR | [ADR-0005](./ADR-0005-ui-package-scope.md) 결정 1 · [ADR-0006](./ADR-0006-btn-primary-contrast.md) |
| 관련 스펙 | [SPEC-04](../spec/SPEC-04_비기능요구사항.md) · PRD 12장(모바일 80%) |

## 맥락

iOS Safari 는 폰트가 16px 미만인 입력창에 포커스가 가면 **페이지를 강제로 확대한다.**
확대된 화면은 사용자가 손으로 되돌려야 하고, 그동안 레이아웃이 뷰포트를 넘는다.

시안의 `.input` 은 `font-size: 14px` 이다 (`styles.css`). 검색이 이 사이트의 핵심 동선이고
PRD 12장이 모바일 트래픽 80% 를 가정하므로, 검색창을 누를 때마다 화면이 튀는 셈이었다.

`.search-box__input`(15px)은 `app.css` 에 있어 이슈 080 에서 16px 로 올렸다.
남은 것은 **시안 정본의 `.input` 자체** — 어드민 폼 · 로그인 · 재료 검색이 전부 여기 걸린다.

## 선택지

**가.** `styles.css` 의 `.input` 을 16px 로 고친다 — 시안 정본을 바꾼다.
**나.** `app.css` 에서 터치 기기에만 16px 로 덮는다.
**다.** 두지 않는다 — 확대를 감수한다.

## 결정

**나를 고른다. `app.css` 에서 `@media (pointer: coarse)` 일 때만 16px 로 덮는다.**

```css
@media (pointer: coarse) {
  .input { font-size: 16px; min-height: 44px; }
}
```

`min-height: 44px` 을 함께 준다. 같은 검토에서 나온 WCAG 2.5.5 터치 타깃 권고를 한 번에 만족시키고,
16px 글자에 36px 높이는 위아래가 답답하다.

가를 고르지 않은 이유: 시안 원본(`docs/design/source/`)과 `styles.css` 가 어긋난다.
ADR-0006 이 같은 상황에서 정한 방식이 있고, 그 방식이 드리프트를 만들지 않는다.

다를 고르지 않은 이유: 모바일이 주 트래픽인데 핵심 동선에서 화면이 튄다. 고칠 수 있는데
안 고치는 것은 SPEC-00 §4 가 허용하는 예외의 경우가 아니다 (ADR-0006 이 같은 문장을 썼다).

### 왜 미디어쿼리인가

데스크톱 어드민 폼은 한 화면에 입력이 여러 줄 들어간다. 거기서 16px·44px 은 밀도를 해친다.
`pointer: coarse` 는 **손가락으로 가리키는 기기**를 뜻하므로, 확대가 실제로 일어나는 환경과
터치 타깃이 필요한 환경이 정확히 같은 조건으로 묶인다. 화면 폭(`max-width`)이 아니라 입력 방식을
기준으로 삼은 이유다 — 좁은 창의 데스크톱 브라우저는 확대되지 않는다.

### 시안 정본은 그대로다

`styles.css` 를 고치지 않고 `app.css` 에서 덮는다
([ADR-0005](./ADR-0005-ui-package-scope.md) 결정 1). 시안 원본과 `styles.css` 는 계속 같은 값이다.

| 자리 | 어디 | 이전 → 이후 |
|---|---|---|
| `.input` (터치 기기) | `styles.css` → `app.css` 로 덮음 | 14px / 36px → **16px / 44px** |

## 되돌리는 조건

1. **시안이 개정된다** — `.input` 이 16px 로 바뀌면 덮개가 필요 없어진다. `app.css` 의 미디어쿼리를 지운다.
2. **iOS 가 규칙을 바꾼다** — 16px 미만에서 확대하지 않게 되면 남는 근거는 터치 타깃뿐이라,
   `min-height` 만 남기고 `font-size` 를 뺀다.

## 영향

- 어드민 폼 · 로그인 · 재료 검색이 터치 기기에서 확대를 일으키지 않는다
- 같은 입력창이 터치 기기에서 44px 이 되어 WCAG 2.5.5 를 만족한다
- [G-51](../prd/GAPS.md#g-51) 이 닫힌다
- 데스크톱은 달라지지 않는다 — 14px / 36px 그대로다
