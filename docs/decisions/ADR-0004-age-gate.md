# ADR-0004 · 전면 성인 인증 게이트를 두지 않는다

| | |
|---|---|
| 상태 | 확정 (법률 검토 대기 조건부) |
| 일자 | 2026-08-06 |
| 대체 | PRD `R-F5-4`, NFR 12장 "성인 인증" |
| 관련 갭 | [G-12](../prd/GAPS.md#g-12) |

## 맥락

PRD `R-F5-4`는 이렇게 적혀 있었다.

> 성인 인증. 최초 진입 시 생년월일 게이트. **주류 콘텐츠 서비스로서 필수다.**

"필수다"의 근거가 문서 어디에도 없다. 검증되지 않은 전제였고,
그 전제 하나가 `PRIN-T04`(SEO 정적 우선)와 정면으로 충돌하고 있었다.

## 판단

성인 인증이 요구되는 전형적 근거는 셋인데, 이 서비스는 그중 하나에만 부분적으로 걸린다.

| 근거 | 해당 여부 |
|---|---|
| 주류 판매 | ❌ PRD 2.3이 명시적 비목표. 이커머스·픽업 커머스 모두 안 한다 |
| 청소년유해매체물 지정 | ❌ 칵테일 레시피·바 소개는 지정 유형이 아니다 |
| 주류 광고 규제 | ⚠️ **부분 해당** — 수익모델의 "브랜디드 콘텐츠"가 주류 브랜드 광고인 경우 |

즉 규제 접점은 **사이트 전체가 아니라 브랜디드 콘텐츠라는 한 종류**다.
그것 때문에 전면 게이트를 세우는 것은 범위가 맞지 않는다.

### 비용은 크고 실효는 없다

- **SEO와 충돌한다.** 게이트가 SSG 경로 앞에 서면 크롤러가 콘텐츠를 못 본다.
  "유기 검색 유입 50% 이상"(PRD 2.2)과 `PRIN-T04`가 동시에 성립할 수 없다.
- **우회 설계는 더 나쁘다.** 크롤러만 통과시키면 클로킹 위험이 있고,
  그렇게 만들면 사람도 우회할 수 있어 어차피 실효가 없다.
- **생년월일 자가신고는 방어력이 없다.** 아무 날짜나 넣으면 통과한다.
  법적 방어 수단으로 약하면서 첫 방문 이탈이라는 비용만 확실히 지불한다.

## 결정

**전면 성인 인증 게이트를 두지 않는다.** 규제 접점에 국소적으로 대응한다.

### 삭제

| 대상 | |
|---|---|
| `R-F5-4` | 전면 생년월일 게이트 |
| `FR-USER-002` | 게이트 구현 |
| `FR-USER-003` | "게이트가 정적 경로 색인을 막지 않는다" — 게이트가 없으면 불필요 |
| `AgeVerification` | 도메인 개념 · ERD 테이블 |

### 유지

| 대상 | 이유 |
|---|---|
| 과음 경고 문구 (`R-F1.1-8`) | 비용 0, 이미 구현됨, 관행 |
| 미성년자 대상 광고 금지 | 광고 운영 규칙이지 게이트가 아니다 |
| 제휴 콘텐츠 라벨 (`R-F4.2-3`) | 공정위 의무. 성인 인증과 무관 |

### 신설

| ID | 내용 |
|---|---|
| `FR-USER-002'` | 주류 브랜드가 등장하는 브랜디드 콘텐츠에 한해 주류광고 고지를 표기한다. `R-F1.3-3`의 광고성 구분 표기와 같은 지점에서 처리한다 |

## 이 결정의 한계

**법률 판단이 아니다.** 위는 서비스 구조로 본 읽기다.

PRD 15장이 이미 "주류 광고 규제 위반 → 법률 검토 1회 필수"를 리스크 대응으로 잡아뒀다.
그 검토 항목에 **"전면 성인 인증이 실제로 요구되는가"** 를 명시적으로 넣는다.

## 되돌리는 조건

법률 검토에서 전면 게이트가 필요하다는 결론이 나오면 되돌린다.
그때는 **게이트와 SEO 중 하나를 포기해야 한다** — 둘 다 가지는 설계는 없다.
그 경우 PRD 2.2의 "유기 검색 유입 50%" 목표를 함께 조정해야 한다.

## 결과

- [G-12](../prd/GAPS.md#g-12)가 해소됐다. B등급에서 가장 위험했던 항목이다.
- `PRIN-T04`의 "게이트가 정적 경로 앞을 막지 않는다"는 단서가 불필요해졌다.
- Phase 1에서 `USER` 도메인의 P0가 하나 줄었다.
