## 읽는 법

- ID는 `FR-<도메인>-nnn`. 도메인 코드는 [SPEC-01 §2](./SPEC-01_시스템개요_범위.md).
- **근거** 열의 `R-xx`는 PRD 요구사항, `PRIN-xx`는 [개발원칙](./SPEC-00_개발원칙.md),
  `INV-`/`GATE-`는 [도메인모델](./SPEC-02_도메인모델.md).
- **우선순위** — `P0` Phase 1 필수 · `P1` Phase 1 선택 · `P2` Phase 2 · `P3` Phase 3.
- `P2`·`P3`은 ID와 한 줄만 잡아둔다. 지금 상세히 쓰면 착수 전에 반드시 틀린다.
