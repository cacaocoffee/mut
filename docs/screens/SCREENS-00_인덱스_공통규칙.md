## 2. 페이지 골격

모든 페이지가 같은 뼈대를 쓴다.

```
┌─────────────────────────────────────────┐
│ .site-nav        브랜드 + 탭 (sticky)     │
├─────────────────────────────────────────┤
│ .shell                                  │
│   .page-head    h6 kicker / h1 / 리드문  │
│   ─────────── 2px rule ───────────      │
│   본문                                   │
├─────────────────────────────────────────┤
│ .legal           과음 경고 (모든 페이지)   │
└─────────────────────────────────────────┘
```

| 요소 | 규칙 |
|---|---|
| `.site-nav` | `position: sticky; top: 0`. 배경은 `--color-bg` — 반투명으로 처리하지 않는다 |
| `.page-head` | `h6` kicker(accent) → `h1` → 우측 리드문. **하단에 2px 규칙선** |
| `.legal` | **모든 페이지 하단 고정.** 제거 불가 (`FR-COCKTAIL-028` · `FR-USER-003`) |

`h1`은 페이지당 하나다. 섹션 제목은 `h4`, 필터 그룹 라벨은 11px uppercase.

## 3. 상태

### 3.1 다섯 가지

| 상태 | 언제 | 표현 |
|---|---|---|
| **정상** | 데이터 있음 | — |
| **빈 결과** | 조건에 맞는 항목 0건 | `.empty-state` — 제목 + 다음 행동 안내 |
| **로딩** | 최초 진입 · 전환 | 스켈레톤. 스피너를 쓰지 않는다 |
| **에러** | 요청 실패 | 무엇이 실패했는지 + 재시도 |
| **권한 없음** | 스코프 밖 | **404 화면.** "권한 없음"을 보여주지 않는다 |

### 3.2 빈 결과

**"결과 없음"만 쓰지 않는다.** 무엇을 하면 결과가 나오는지 말한다.

```
조건에 맞는 항목이 없습니다
도수 구간을 넓히거나 맛/향 태그를 줄여보세요.
```

제안은 **가장 많이 걸러낸 축**을 지목한다. 향·맛은 AND라서 대개 여기가 범인이다
([SPEC-07 §3.1](../spec/SPEC-07_API명세.md)).

### 3.3 로딩

스켈레톤은 **실제 콘텐츠와 같은 골격**을 갖는다 — 카드 그리드면 카드 모양,
표면 행 모양. 레이아웃이 튀지 않아야 한다.

정적 생성 경로(칵테일·바 상세, 카테고리)는 **로딩 상태가 없다.**
SSG라 HTML이 이미 완성돼 있다 (`PRIN-T04`).

### 3.4 권한 없음은 404다

`403`을 화면에 노출하지 않는다. "이 바에 접근할 수 없습니다"는
**그 바가 존재한다는 사실을 알려준다** ([SPEC-08 §3.2](../spec/SPEC-08_보안_권한_개인정보.md)).

`draft` 콘텐츠도 마찬가지다. 비로그인 사용자에게는 존재하지 않는 것과 같다.

### 3.5 에러

| 상황 | 문구 방향 |
|---|---|
| 네트워크 실패 | "불러오지 못했습니다" + 재시도 버튼 |
| 발행 게이트 실패 | **실패 항목 전부를 목록으로** (`FR-ADMIN-003`) |
| 레이트 리밋 | "잠시 후 다시 시도해주세요" + `Retry-After` 반영 |

서버가 준 `violations[]`의 `code`로 분기하고, `message`를 그대로 노출한다
([SPEC-07 §1.4](../spec/SPEC-07_API명세.md)). 클라이언트가 문구를 다시 만들지 않는다.

## 4. 반응형

Modernist 시안은 데스크톱 그리드만 잡았다. 그 배치를 최상단으로 두고 아래로 무너뜨린다.
**PRD 12장이 모바일 트래픽 80%를 가정하므로 반응형은 선택이 아니다.**

| 폭 | 무엇이 바뀌나 |
|---|---|
| ≥1081px | 시안 원본 — 사이드바 필터 296px + 카드 3열 |
| ≤1080px | 카드 2열 · 상세 2단 → 1단 |
| ≤840px | **필터 사이드바가 상단으로** · shell 패딩 32→16px · `h1` 56→38px |
| ≤560px | 카드 1열 · 파인더 선택지 1열 · 탭 줄바꿈 |

가로 스크롤을 만들지 않는다. 넓은 표는 자체 컨테이너에서 스크롤한다.

## 5. 디자인 시스템 사용

정본은 `packages/ui/styles.css`다. 규칙은 [docs/design/](../design/)에 있고, 화면에서 반복하지 않는다.

화면 문서가 알아야 할 것만:

- **라운드 0.** 어디에도 주지 않는다
- **전부 왼쪽 정렬.** 넓은 버튼 안의 레이블도
- 섹션 사이는 **2px 규칙선**. 여백으로 대체하지 않는다
- 사진은 `.grayscale` 래퍼를 통과한다
- accent는 주요 액션과 작은 강조에만

새 화면을 만들 때 **`app.css`에 있는 클래스를 두고 평행한 것을 새로 만들지 않는다.**

## 6. 접근성

| 항목 | 규칙 |
|---|---|
| 대비 | WCAG AA. **accent↔ground는 3:1이라 본문 크기 텍스트에 못 쓴다** → `--color-accent-700` |
| 포커스 | `:focus-visible` 2px accent 아웃라인. 브라우저 기본 링을 남기지 않는다 |
| 필터 칩 | `aria-pressed`로 선택 상태. 0건은 `disabled` |
| 탭 | 현재 위치는 `aria-current="page"` |
| 이미지 | `alt` 필수. 장식용은 빈 `alt` |
| 차트 | SVG에 `role="img"` + `aria-label`. 수치는 **표로도 제공** |
| 모션 | `prefers-reduced-motion` 존중 |

**색만으로 정보를 전달하지 않는다.** 당도 태그는 색이 다르지만 글자도 다르고,
파트너 배지는 색이 다르지만 라벨도 붙는다.

---

## 7. 카피

시안의 문체를 따른다.

- **한글 우선, 영문 병기.** `칵테일 탐색` + `Browse 24 entries`, `당도 SWEETNESS`
- 라벨은 `국문 ENGLISH` 순, 영문은 11px uppercase `letter-spacing: .08em`
- 숫자는 `font-variant-numeric: tabular-nums`. 흔들리지 않아야 한다
- **단정형으로 쓴다.** "~할 수 있습니다"보다 "~합니다"
- 느낌표를 쓰지 않는다

---

## 8. 이미지

실제 자산이 없는 동안 시안의 **사선 해칭 자리표시자**를 쓴다 (`.photo-slot`).

| 비율 | 쓰는 곳 |
|---|---|
| 4:5 | 칵테일 카드 · 상세 히어로 |
| 4:3 | 파인더 결과 카드 |
| 3:2 | 에디토리얼 |

실제 이미지가 들어와도 **`.grayscale` 래퍼는 유지한다.** 콘텐츠 사진은 흑백 출력이 원칙이다.

## 9. 법적 표기

| 표기 | 어디 | 근거 |
|---|---|---|
| 과음 경고 | **모든 페이지 하단** | `FR-COCKTAIL-028` |
| `제휴 콘텐츠` 라벨 | 협찬 콘텐츠 **상단** | `FR-PARTNER-005` — 공정위 의무 |
| 주류광고 고지 | 브랜디드 콘텐츠 | `FR-USER-002` |
| 파트너 배지 | 목록·상세 일관되게 | `FR-PARTNER-002` |

**파트너 배지와 `제휴 콘텐츠` 라벨은 절대 같은 색을 쓰지 않는다** (`FR-PARTNER-006`).
앞은 등급 정보고 뒤는 법적 고지라 성격이 다르다.

라벨을 축소하거나 흐리게 처리하는 스타일 변경은 `PRIN-P02` 위반이다.

전면 성인 인증 게이트는 **없다** ([ADR-0004](../decisions/ADR-0004-age-gate.md)).
콘텐츠 앞에 인터스티셜을 세우지 않는다.

|---|---|---|
| 카테고리 | `/cocktails/base/gin/` 단일 축만 | ✅ |

| 필터 | `/?base=gin&flavor=citrus` | ❌ `noindex` |

조합 폭발은 중복 콘텐츠 페널티를 부른다.

공유(`FR-USER-005`) — 모든 공개 페이지에 OG 태그. 카카오톡 카드형 미리보기가 뜨는지
발행 전 확인한다.

## 11. 인증 진입

로그인은 **막는 게 아니라 필요할 때 요청한다.**

| 행동 | 비로그인 |
|---|---|
| 조회 · 필터 · 검색 | 그대로 가능 |
| 내 술장 체험 | **로컬 저장으로 가능** (`R-F2.2-4`) |
| 저장 · 컬렉션 | 이 시점에 로그인 유도 |

로그인 유도는 모달로 띄우되 **뒤 콘텐츠를 가리지 않는 크기**로 한다.
"로그인해야 볼 수 있습니다" 같은 벽을 콘텐츠 앞에 세우지 않는다 (`PRIN-T04`).

소셜 3종(카카오 · 네이버 · 애플)을 동등하게 배치한다 (`FR-USER-001`).
