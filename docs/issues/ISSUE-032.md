## 근거

**ADR-0004 — 전면 성인 인증 게이트를 두지 않는다** (사용자가 IDE에서 연 문서)

**`FR-USER-002`**: **전면 성인 인증 게이트를 두지 않는다.** 주류 브랜드가 등장하는 **브랜디드 콘텐츠에 한해 주류광고 고지**를 표기한다 — `R-F1.3-3`의 광고성 구분 표기와 **같은 지점에서 처리**한다
**`FR-USER-003`**: **과음 경고 문구**와 **미성년자 대상 광고 금지**는 유지한다. 이는 **광고 운영 규칙이지 접근 게이트가 아니다**
**`FR-COCKTAIL-028`**: 과음 경고와 미성년자 판매 금지 문구를 **페이지 하단에 고정 노출** (`R-F1.1-8`)

**`PRIN-T04`**: **콘텐츠 앞에 인터스티셜을 세우지 않는다.** 크롤러가 콘텐츠를 못 보면 SEO 요구와 정면 충돌한다. **전면 성인 인증 게이트를 폐기한 이유가 이것이다**

**`NFR-S-08`**: **콘텐츠 앞에 인터스티셜을 두지 않는다** — 배포 차단
> `NFR-S-08`이 ADR-0004를 요구사항으로 굳힌 것이다. **법률 검토가 성인 인증을 요구하면 이 항목과 정면 충돌하며, 그때는 목표 수치를 함께 조정해야 한다**

**SPEC-08 §8 법적 요구** — 성인 인증은 폐기됐다. **남은 것:**

| 요구 | 어디서 |
|---|---|
| 과음 경고 문구 **고정 노출** | **전 페이지 하단** (`R-F1.1-8`) |
| `제휴 콘텐츠` 라벨 | `article.is_sponsored` 기반, **렌더링 강제** (`R-F4.2-3`) |
| 브랜디드 콘텐츠 **주류광고 고지** | `FR-USER-002` |
| 미성년자 대상 광고 금지 | **광고 운영 규칙 — 시스템 기능이 아니다** |
| 개인정보 처리방침 · 이용약관 | **정적 페이지** |

**`NFR-L-01`**: 과음 경고가 **모든 페이지** 하단에 있다 — **배포 차단**
**`NFR-L-02`**: `is_sponsored` 콘텐츠에 `제휴 콘텐츠` 라벨이 **끌 수 없게** 표기 — 배포 차단 · **공정위 의무**
**`NFR-L-03`**: 파트너 배지와 제휴 라벨이 **다른 색** — 배포 차단
**`NFR-L-04`**: 개인정보 처리방침 · 이용약관 페이지 존재 — 배포 차단

**SPEC-02 §5.3 배지 색 규칙**: 파트너 배지와 `제휴 콘텐츠` 라벨은 **절대 같은 색을 쓰지 않는다.** 앞은 등급 정보고 뒤는 법적 고지라 성격이 다르다. 표현 규칙은 **SCREENS-00 §9**

**`PRIN-P02`**: **라벨을 축소하거나 흐리게 처리하는 스타일 변경도 이 원칙 위반이다**

**CONVENTIONS §4**: `packages/ui` **수정 금지** (ADR-0001 — 시안 정본)


`app/layout.tsx`에 **무조건 렌더**한다. props로 숨길 수 없게 한다 (RED 7·16).

```tsx
// NFR-L-02 · INV-INGREDIENT-02 — 끌 수 없는 라벨
export function SponsoredLabel({ isSponsored }: { isSponsored: boolean }) {
  if (!isSponsored) return null;
  return <span className="sponsored-label">제휴 콘텐츠</span>;
}
```

**`hidden`·`variant` 같은 prop을 두지 않는다** (RED 16). 있으면 언젠가 쓰인다 — `PRIN-P02`의 논리 그대로다.
