## 근거

**`FR-ADMIN-001`** (P0): **에디터가 개발자 없이 콘텐츠를 발행할 수 있어야 한다** (PRD 12장)
**`NFR-O-01`**: 에디터가 개발자 없이 발행 — **신규 1건을 어드민만으로 완료** (인수 시나리오)

**`FR-ADMIN-003`**: 발행 게이트 실패 시 실패한 항목을 **전부 한 번에** 보여준다. **하나씩 고치게 하지 않는다**
**`FR-ADMIN-006`** (P0): **노출 규칙을 어드민에서 조정할 수 없다. 입력란 자체를 만들지 않는다** (`PRIN-P02`)

**`FR-COCKTAIL-002`**: `style_primary`는 `styles`에 포함된 값 중에서만 고를 수 있다. **UI가 `styles` 선택 결과로 후보를 좁힌다**
**`FR-COCKTAIL-008`**: 향·맛 태그를 1~3개로 선택. **4개째는 UI가 막는다**
**`FR-COCKTAIL-014`**: `slug`는 최초 발행 이후 변경 불가. **어드민에서 입력란을 비활성화한다**

**`PRIN-T05`**: **프론트 검증은 UX용 중복이다. 없어도 데이터가 깨지지 않아야 한다** — UI가 막는 것은 편의이고, 서버가 정본

**SPEC-05 §1**: 어드민 = Next.js **`/admin` 라우트 그룹**. **별도 앱을 만들지 않는다** — 디자인 시스템과 인증을 공유
**SPEC-05 §4**: `/admin/*` — **CSR (인증)**, 색인 ❌
**SPEC-04 §1.1**: `/admin/*` — **LCP 예산 없음** (내부 도구)

**SPEC-08 §2**: 칵테일 생성/수정·발행/회수 = `editor`·`admin`. **재료 승인은 `admin`만**
**SPEC-08 §4.1**: `editor`/`admin` 세션 **8시간 절대** — 공용 PC에 남은 세션으로 아무나 발행할 수 없게

**SPEC-07 §1.2**: Next.js 서버 컴포넌트에서 API 호출 시 **들어온 쿠키를 그대로 전달**

## GREEN

### `app/admin/` 라우트 그룹 (SPEC-05 §1)

**별도 앱을 만들지 않는다.** 같은 Next.js 앱의 라우트 그룹이다 — 디자인 시스템과 인증을 공유한다.

```
app/admin/
├─ layout.tsx              인증 가드 + 어드민 셸
├─ cocktails/
│  ├─ page.tsx             목록
│  ├─ new/page.tsx
│  └─ [id]/page.tsx        편집 + 발행 조건 패널
├─ ingredients/page.tsx    승인 큐 (admin only)
├─ tasks/page.tsx          검증 태스크
└─ audit/page.tsx          감사 로그 (admin only)
```

### 발행 조건 패널 (RED 9~15 — SCREENS-06 정본)

```tsx
// FR-ADMIN-003 — 실패 항목을 전부 한 번에. 하나씩 고치게 하지 않는다
{violations.map(v => (
  <GateFailure key={v.code} code={v.code} field={v.field} message={v.message} />
))}
```

서버가 `violations` 배열을 통째로 준다 (이슈 003·013·025). **프론트는 전부 렌더할 뿐 잘라내지 않는다.**

### 입력 강제는 UX (RED 23, `PRIN-T05`)

> **프론트 검증은 UX용 중복이다. 없어도 데이터가 깨지지 않아야 한다.**

`style_primary` 후보 좁히기·향맛 4개째 차단은 **편의**다. 서버가 정본이고, RED 23이 그것을 확인한다.

### 노출 규칙 입력란 부재 (RED 24~28)

이슈 027의 프론트판이다. **폼 필드 스캔 테스트**로 고정한다:

```tsx
// PRIN-P02 · FR-ADMIN-006
// 이 목록의 입력란을 만들면 테스트가 빨갛게 된다.
const FORBIDDEN_FIELDS = ["boostLimit", "homeSlotRatio", "sponsorLabelVisible"];
```

### 이미지 (RED 42 — ⚠️ G-07)

**이미지 없이 발행 가능**해야 한다. `GATE-COCKTAIL-01~06` 어디에도 이미지 요구가 없으므로 (SPEC-02 §2.3) 성립한다.

저장소 확정 후 `POST /admin/media`를 붙인다. **GAPS 등재.**

- `packages/ui` 수정 (ADR-0001)
- 노출 규칙 입력란 (`PRIN-P02`)
- 이미지 파이프라인 — G-07
- 별도 어드민 앱 (SPEC-05 §1)
