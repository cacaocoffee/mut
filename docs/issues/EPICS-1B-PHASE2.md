# Phase 1b · Phase 2 이후 — 에픽 개요

> **왜 에픽까지만인가**: Phase 1a 완료 전에 쪼개면 실제 구현 형태를 모른 채 추정하게 된다.

> **1a 종료 시점에 각 에픽을 `INDEX.md` 형식의 이슈로 재분해한다.**

범위 근거: [`SPEC-01 §4.2·§4.4`](../spec/SPEC-01_시스템개요_범위.md) · [`SPEC-03 §8`](../spec/SPEC-03_기능요구사항.md)

## Phase 1b — 그래프 완성 (P0 21건)

**한 줄 목표**: 칵테일↔바 **양방향 순환**을 만든다.

**SPEC-01 §4.3이 지불한 비용을 회수하는 단계다.**

> **`PRIN-P01`(그래프가 제품이다)이 1b까지 검증되지 않는다.**
> 칵테일↔바 양방향 연결이 이 제품의 해자이고, PRD 2.2가 크로스 이동률을 "진짜 검증 지표"로 지목했다. **1a만으로는 레시피 사이트와 구별되지 않는다.**

**종료 판정** (SPEC-01 §8.2): 서울 바 100곳 발행 · 시그니처 메뉴가 칵테일에 연결 · **`cross_nav` 관측** · **크로스 이동률 세션의 20%**
